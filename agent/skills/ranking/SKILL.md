# Рейтинги вузов

Если пользователь не просил сравнить рейтинги, используй один рейтинг издателя. Укажи его название и год, если они есть в материале. Для общего запроса достаточно трёх примеров. Для каждого вуза скопируй отдельную полную строку или короткое непрерывное предложение, которое подтверждает его место. Не склеивай строки и не вставляй многоточия в цитату. Когда точные места не видны, назови только вузы, которые источник относит к лидерам.

Связывай каждое место или включение в лидеры с его собственной выдержкой. Фраза о первом месте и об обгоне двух вузов не подтверждает их точные позиции и попадание других вузов в первую пятёрку. Сократи список до того, что можно доказать.
