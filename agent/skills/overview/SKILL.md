# Кратко о вузе

Дай короткую справку. Начни с названия из официального источника, укажи город и один подтверждённый факт о профиле вуза, если они есть в материалах. Одного подтверждённого факта достаточно для полезного ответа. Не перечисляй рейтинги, статистику, количество программ и условия приёма без отдельной просьбы. Поставь маркер рядом с каждым существенным фактом.
