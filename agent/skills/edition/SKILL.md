# Редакция на дату

Найди документ и проверь, что редакция действовала на указанную дату для нужного вуза, филиала и категории. Если источники расходятся, сравни даты и область действия. Для проверяемого сравнения можно добавить блок kind edition в поле blocks с title, columns и rows. Каждая ячейка содержит value и ref с позицией в citations либо null. Дата публикации сама по себе не доказывает период действия.
