# Расчёт

Чтобы выполнить простое действие с подтверждёнными числами, добавь в blocks объект kind calculation с title, operator (+, -, * или /) и двумя элементами operands. Каждый операнд содержит value как десятичную строку с точкой и ref с позицией в citations. Используй числа с подходящими единицами и одинаковыми условиями. Код проверяет операнды и считает итог. Не приписывай результат другой сумме или периоду.
