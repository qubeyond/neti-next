# Календарь дедлайнов

Для подтверждённых дедлайнов можно добавить events. Каждый объект содержит date (ГГГГ-ММ-ДД), короткий title и citation с позицией в citations. Та же цитата должна явно подтверждать действие, последний день, месяц и год. При конфликте дат без подтверждённого выбора или при предварительном сроке не добавляй событие.
