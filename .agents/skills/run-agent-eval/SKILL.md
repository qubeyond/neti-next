---
name: run-agent-eval
description: Проверка качества поиска, генерации, цитирования или стоимости агента NETI Next на существующих кейсах и добавление регрессий в eval.
---

1. Возьми режим и срез из [evals/AGENTS.md](../../../evals/AGENTS.md). Поиск измеряй через `retrieval`, работу по известным доказательствам через `oracle`, весь путь через `e2e`.
2. Для причинной проверки одной правки сохраняй вопросы, эталоны и рубрику. При неизменном поиске переиспользуй результат через `--reuse-search`.
3. Проверь знаменатели, ошибки формата и провайдеров. Отличай дословное совпадение цитаты от подтверждения факта.
4. Сохрани сравнение в [отчёте соответствующей версии](../../../docs/metrics/AGENTS.md). Запросы с ключами расходуют квоту. Для пилота используй небольшой парный срез, для подтверждения фиксируй другие группы источников заранее. Полный eval запускай при существенном изменении архитектуры относительно бейзлайна.
5. Если проверяешь гипотезу, запиши вывод по [исследовательскому циклу](../../../agent/AGENTS.md#исследовательский-цикл). В конце серии используй [form-research-hypotheses](../form-research-hypotheses/SKILL.md), чтобы разобрать результаты и выбрать следующий пилот.
