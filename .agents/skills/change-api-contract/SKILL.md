---
name: change-api-contract
description: Изменение маршрутов Go или FastAPI, JSON ответа или использования API в интерфейсе NETI Next.
---

1. Определи сервис-владелец маршрута и потребителей контракта. Go обслуживает `/api/…`, FastAPI агента — `/agent/…`. JSON CLI агента может иметь дополнительные поля.
2. Уточни изменение публичного контракта и сохрани совместимость там, где задача её требует.
3. Обнови тест маршрута и проверку пользовательского состояния. Для маршрутизации сверь Vite и nginx, затем выполни `make -C deploy smoke`.
4. Выполни `make -C deploy check`. В PR отрази изменения контракта и выполненные проверки.
