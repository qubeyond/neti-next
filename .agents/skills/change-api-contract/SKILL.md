---
name: change-api-contract
description: Изменение маршрутов Go или FastAPI, JSON ответа или использования API в интерфейсе NETI Next.
---

1. Определи владельца маршрута и потребителей. Используй [правила HTTP-контрактов](../../../docs/api-contracts.md) для схемы, совместимости и публикации.
2. Проверь маршрут по обновлённому контракту, включая ожидаемые ошибки. В UI проверь затронутое состояние, если оно меняется.
3. Для межсервисного изменения запусти `make -C deploy check`, для маршрутизации добавь `make -C deploy smoke`. В PR укажи изменение, ссылку на схему и результаты проверок.
