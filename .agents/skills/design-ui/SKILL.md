---
name: design-ui
description: Проектирование или проверка сценария интерфейса NETI Next, включая чат, цитаты, уточнения, ошибки и мобильный вид.
---

1. Начни с пользовательской задачи из [спецификации](../../../docs/spec.md). Опиши вход, действие и следующий шаг. Показывай только полезные для них элементы.
2. Спроектируй состояния ожидания, успеха, уточнения, недостаточного подтверждения и ошибки. Начало нового диалога должно быть доступно через явное действие.
3. Свяжи состояния с реальным HTTP-контрактом. Подтверждение и доступ определяет сервер. Тексты и цитаты отображай как текст.
4. Проверь клавиатуру, фокус, чтение и переход по цитате, узкий и широкий экран. Проверь TypeScript, сборку и прокси по [frontend/AGENTS.md](../../../frontend/AGENTS.md).
