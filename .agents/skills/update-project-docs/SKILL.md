- Формулировку организаторов и баллы сохраняй в [track](../../../docs/track.md), поведение и приёмку — в [spec](../../../docs/spec.md).
- Выбор и причины записывай в ADR владельца через [индекс](../../../docs/AGENTS.md). Используй устойчивые идентификаторы и ссылку на новое решение при замене.
- Статус, зависимости и доказательство приёмки обновляй в [stages](../../../docs/stages.md). Замеры сохраняй по [формату отчётов](../../../docs/metrics/AGENTS.md).
- Правила выполнения храни в AGENTS.md, повторяемые процедуры — в навыках. README остаётся краткой справкой.
- Проверь внутренние ссылки и соответствие документа коду, данным и реальному выводу проверок.
