---
name: release-app
description: Проверка релизного workflow, подготовка deployment или откат production-образов NETI Next.
---

1. Прочитай [deploy/AGENTS.md](../../../deploy/AGENTS.md), проверь текущую ветку, SHA релиза и статусы CI.
2. Дополни локальную проверку `make -C deploy smoke` при изменении runtime. Убедись, что workflow публикует все образы с одним SHA.
3. При порученной выкладке проверь окружение и доступ на чтение GHCR. Для SSH используй заданный host key. Ничего из production env не выводи в отчёт.
4. Успех означает здоровый стек и указатель `current` на нужный SHA. При сбое выясни, запустился ли предыдущий релиз, и зафиксируй результат.
