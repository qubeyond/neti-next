# Бэкенд

Самостоятельный Go-сервис. Текущий контракт — `GET /api/health`.

- Храни серверный код и его зависимости внутри `backend/`. Добавляй продуктовые маршруты и хранилища по мере появления требований.
- Сохраняй healthcheck свободным от сетевых вызовов и ключей. Доступ извне в полном стеке идёт через прокси фронтенда.
- `BACKEND_PORT` принадлежит Go и описан в `.env.example`. При изменении порта в стеке сверь `BACKEND_UPSTREAM` фронтенда.
- Проверяй формат через `gofmt -l .` и тесты через `go test ./...` из `backend/`. Dockerfile проверяет формат и компилирует сервис. Общий smoke проверяет живой HTTP.
- Отдельный образ собирается как `docker build -t neti-backend .` из этой папки. Для локального запуска можно использовать `go run .` или контейнер с `--env-file .env`.
