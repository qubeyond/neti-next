# ADR фронтенда

## FE-01 · React и относительные API-адреса

- **Дата и статус** — 2026-11-20, принято.
- **Контекст** — Стартовую страницу нужно собирать независимо и подключать к сервисам в общем Compose или на разных хостах.
- **Решение** — React с TypeScript и Vite, статическая сборка в nginx. Относительные `/api/…` и `/agent/…` маршрутизируются прокси. Адреса upstream задаются окружением фронтенда.
- **Последствия** — UI не переносит адреса провайдеров и их ключи в браузер. Для раздельного развёртывания достаточно поменять upstream и проверить HTTP/TLS. Прокси в dev и prod должны сохранять одинаковые пути.
- **Пересмотр** — На ST-05 определить, какие прикладные операции идут через Go после утверждения контракта диалога.
