# ADR оценивания

## EVAL-ADR-01 · Оценивать этапы отдельно

- **Дата и статус** — 2026-11-20, принято.
- **Контекст** — Совпадение URL, дословность цитаты и правильность ответа дают разные сигналы.
- **Решение** — Разделять веб-прогон, ранжирование результатов, ответ по готовым доказательствам и отказ на неподходящих фрагментах. Срезы строить по домену и навыку. Эталонные факты и критерии доступны оценщику.
- **Последствия** — Сравнение показывает, где теряется факт: в поисковой выдаче, переданном фрагменте или ответе. Сохраняй отдельные знаменатели и сбои оценки. Выборочная ручная сверка нужна для интерпретации автоматического вердикта.
- **Пересмотр** — При внедрении многоходового режима выделить свою единицу измерения и набор вопросов. При добавлении RAG использовать сопоставимый срез и отложенную выборку.
