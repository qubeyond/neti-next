# Профили и чаты NETI Next

Связано с DIALOG-01 и UI-01. Браузер обращается к Go по [контракту рабочего пространства](../api/backend.openapi.json). Go владеет профилями, чатом, временем запуска и данными файлов. Текущий FastAPI принимает одиночный вопрос.

## Сценарии проверки

- Создать два демо-профиля. Для каждого создать диалог, отправить вопрос и перезагрузить страницу. Чаты и вложения доступны только своему профилю. Запрос к чужому идентификатору возвращает 404.
- Открыть два чата в одном профиле. В адаптер ответа приходит только история выбранного чата. Повтор запроса с тем же идентификатором не создаёт новую пару сообщений.
- Включить инкогнито, отправить текст и файл и перезагрузить страницу. Профиль остаётся доступным и не содержит гостевых сообщений. Гостевой токен живёт в памяти вкладки. Go держит гостевые данные в памяти до выхода из режима, рестарта или часа бездействия.
- Отправить файл и голосовую запись. Из сообщения файл можно скачать, поддерживаемое изображение или аудио можно открыть. В одном сообщении до пяти вложений по 16 МиБ. Для записи нужен HTTPS или localhost.
- Проверить доступ к цитате, копирование, вопрос по выделенному фрагменту, сохранение темы и имени, смену пароля, удаление истории и аккаунта.
- В dev и prod WebSocket через прокси информирует браузер об изменениях. Браузер перечитывает сохранённое состояние при возвращении связи. При ошибке последнюю попытку можно повторить. Готовый ответ печатается по символам, цветной ASCII-голубь рядом с последним ответом двигает ртом во время печати. При включённом сокращении анимации текст показывается сразу.

Проверки `go test -race ./...` из `backend/` и `make -C deploy check` прошли. Браузерный сценарий прошёл на ширинах 1440 и 320 пикселей с контролируемым HTTP-ответом агента и тестовым микрофоном. В dev и prod прошёл Compose smoke. Для загрузки зависимостей использовалась временная сеть хоста на этапе сборки и тот же образ `uv` по digest. Отдельно проверены WebSocket и загрузка 21 КБ через production nginx. Живой FastAPI проверен с выключенными веб-ответами.

## Передача команде агента

Адаптер находится в [backend/agent.go](../../backend/agent.go). Его вход уже содержит идентификатор чата, сообщение с цитируемым фрагментом, метаданные файлов, чтение бинарных данных внутри выбранного чата, историю, имя и пользовательскую инструкцию. Следующий транспорт должен быть согласован с владельцем FastAPI. Текущий вызов передаёт только текущий текст и вошедшую в лимит цитату. Схема FastAPI в этой работе остаётся действующей.

| Возможность | Что нужно от FastAPI |
| --- | --- |
| Контекст изоляции и уточнения | Структурированный вход с историей, отдельным текущим вопросом и цитируемым фрагментом. История берётся Go только из выбранного диалога. Для явного уточнения полезен отдельный статус или поле подсказок. |
| Картинки, аудио и произвольные файлы | Формат передачи содержимого или доступный только сервисам способ чтения бинарных данных, перечень форматов и ограничения. Go хранит файлы у чата, публичные ссылки для агента не выдаёт. |
| Персональная инструкция | Отдельное поле для пользовательской инструкции с приоритетом ниже системных правил агента. |
| Реальные вызовы инструментов | События о старте, окончании и сбое вызова, с типом и кратким пользовательским названием без внутренних аргументов. Go передаёт события в историю ответа и уведомляет браузер по WebSocket. |
| Структурированные артефакты | Поле ответа для изображений, ссылок, цитат, аудио и файлов. Согласовать доступ к медиа и срок жизни URL. Сегодня доступны проверенные цитаты и ссылки, которые агент помещает в текст. |

Демо-регистрация создаёт реальный локальный профиль без подтверждения почты. Запуск с публичным доступом и платным агентом требует внешней политики доступа по [инструкции развёртывания](../../deploy/AGENTS.md).
