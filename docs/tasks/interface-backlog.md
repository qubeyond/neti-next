# Идеи для интерфейса Пигеона

Отметьте идеи, которые берём в работу. Список продолжает [продуктовые идеи](../product-ideas.md) и ориентирован на интерфейс. Основной сценарий — пользователь понимает, для каких условий верен ответ о вузе, видит доказательство и знает следующий шаг.

В текущем интерфейсе уже есть ссылки на цитаты, структурированные таблицы, экспорт дедлайна в календарь, распознавание фото и голоса, остановка запроса и демонстрационная трассировка. Фронтенд может развить эти возможности через [существующий API](../../frontend/src/api.ts).

## Можно сделать на фронтенде

- [ ] **1. Панель «Источники».** Счётчик под ответом открывает список выдержек. Клик по номеру цитаты ведёт к нужной выдержке и ссылке на оригинал. Если известна страница PDF, ссылка открывает её. На мобильном панель выезжает снизу.
- [ ] **2. «Стоп» и «Показать сразу».** Пока агент работает, на месте кнопки отправки показываем «Стоп» и вызываем существующий маршрут отмены. Когда ответ уже получен и печатается на экране, «Показать сразу» выводит полный текст и завершает анимацию речи.
- [ ] **3. Прыжок к новому ответу и черновики.** При чтении старых сообщений сохраняем позицию прокрутки и показываем кнопку «К новому ответу». Черновик сохраняем отдельно для каждого чата в текущей вкладке. Черновики инкогнито исчезают при выходе из режима.
- [ ] **4. Меню «+» и превью вложений.** Собираем «Прикрепить файл» и «Сфотографировать документ» в одном меню. Скриншот можно вставить из буфера обмена. До отправки видны превью, имя файла и ограничение загрузки.
- [ ] **5. Быстрые действия под ответом.** «Короче», «Объясни проще» и «Составь список документов» подставляют запрос и цитату в черновик. Пользователь может отредактировать их перед отправкой.
- [ ] **6. Скачать результат.** Экспортируем ответ с источниками в Markdown, а таблицу сравнения в CSV. Браузер собирает оба файла из полученного ответа.

## Понадобится бэкенд или агент

- [ ] **7. Условия чата.** Показываем вуз, уровень обучения, год кампании и форму финансирования компактными кнопками. **Агент** возвращает распознанные условия отдельными полями и учитывает явные исправления. **Go** хранит условия отдельно для каждого чата. Проверка — заменить «Бюджет» на «Платное» и получить ответ с тем же вузом, уровнем и годом.
- [ ] **8. План поступления.** Выводим список действий, документов и подтверждённых сроков с цитатой у каждого пункта. **Агент** возвращает структурированные пункты с ID, текстом, датой при наличии и ссылкой на доказательство. **Go** сохраняет отметки выполнения, если решили восстанавливать их после перезагрузки. Проверка — открыть источник срока прямо из чеклиста.
- [ ] **9. Меню чата «⋯».** Добавляем «Переименовать», «Закрепить» и «В архив». **Go** обновляет метаданные чата и возвращает их в списке.
- [ ] **10. Поиск по сообщениям.** В результатах показываем совпавшую фразу, а клик открывает нужное сообщение. **Go** ищет по чатам владельца и возвращает ID чата, ID сообщения и фрагмент совпадения. Сейчас интерфейс фильтрует названия чатов.
- [ ] **11. «Изменить вопрос → Новый вариант».** Старый вопрос открывается в черновике, откуда можно продолжить в отдельном чате. **Go** создаёт ветку с историей до выбранного вопроса, сохраняет исходный чат и проверяет доступ к вложениям.
- [ ] **12. «Сообщить об ошибке».** Пользователь выбирает «Срок устарел», «Цитата не подтверждает ответ» или «Пропущено важное». **Go** сохраняет ID сообщения, причину, необязательный комментарий и номер цитаты, если её указали.
- [ ] **13. «Следить за сроком».** При изменении дедлайна показываем прежнюю и новую даты со ссылкой на источник. **Агент и Go** поддерживают подписку, фоновую перепроверку источника и уведомление после подтверждения изменения. Кандидат на этап после хакатона.

## Предложение для хакатона

На фронтенде начать с панели источников и управления ответом (**1–2**). В серверную часть передать контракт для условий чата и плана с цитатами (**7–8**). Поля согласовать по [правилам HTTP-контрактов](../api-contracts.md).

Демосценарий — спросить про поступление в НГТУ, изменить бюджет на платное обучение, получить обновлённый план и открыть документ, подтверждающий один из дедлайнов.
