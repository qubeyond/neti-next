# Ответы, вложения и настройки Пигеона

Связано с UI-01, UI-02 и настройками профиля из [спецификации](../spec.md).

- Ответы используют Markdown с абзацами и списками. Распознанный текст PDF и текстовых документов показан в закрытой карточке «Текст документа», которую можно раскрыть.
- Изображения, PDF, аудио и текстовые вложения открываются в отдельном окне просмотра. Для других форматов доступно скачивание. Текстовый предпросмотр ограничен первыми 200 КБ.
- Настройки увеличены. «Подробнее» объясняет функции Пигеона, источники, вложения и контекст чатов. Пункт языка убран.
- Инструкция профиля применяется со следующего сообщения в чате и трассировке через поле `user_instructions`. Правила описаны в [AGT-15](../adr/agent.md#agt-15--предпочтения-профиля).
- Подключён PR #10 с задумчивой мордочкой и облачком. Во время размышления покачивается только голубь, облачко статично. Снижение анимации учитывается.
- Источники представлены компактными ссылками с доменом сайта и предпросмотром цитаты. Для цитаты из изображения показывается подпись «Фото». Карточки распознанного текста изображений скрыты в чате и трассировке, в том числе в старых ответах.
- После успешного выхода открывается регистрация.
- На страницах аккаунта портрет имеет прямой нижний край.

Браузерные сценарии с подстановкой API покрыли сохранение настройки, открытие изображения/PDF/текста, сворачивание распознанного документа, мордочку размышления, статичное облачко и размер настроек на мобильном экране.

Передача инструкции и изоляция контекста проверяются в `backend/cmd/api/profile_context_test.go` через реальные маршруты регистрации, настроек и чатов, PostgreSQL и HTTP-адаптер со стендом агента. Проверены два чата одного аккаунта, продолжение каждого с точным составом истории, другой аккаунт, гость, изменение и очистка инструкции. `agent/tests/test_profile_instructions.py` проверяет состав запроса модели, приветствие с инструкцией, параллельные запросы и сброс контекста после ошибки. При отключении передачи предпочтений проверка регрессии падает.

Команды проверки: `INFERENCE_URL=http://127.0.0.1:9 AGENT_TOKEN= INFERENCE_TOKEN= make -C deploy check` и `BACKEND_TEST_DATABASE_DSN=… go test -race -count=1 -v ./...` из `backend/` на отдельной временной БД с пустой схемой `backend`. Переменные переопределяются только в процессе проверки; закрытый адрес инференса исключает обращения офлайн-тестов к запущенному живому провайдеру.
