# НЭТИ-НЕКСТ 2.0 · ML-product

- Хакатон проходит 20–22 ноября 2026 года.
- Кейс команды — **Think-About-It-Agent**, базовый кейс трека ML-product.
- Задача — находить открытые сведения о вузах Новосибирска, отвечать на вопросы и сохранять контекст диалога.

## Требования организаторов к кейсу

- Собрать и структурировать открытую информацию с сайтов вузов.
- Создать базу знаний с использованием RAG.
- Находить информацию, релевантную вопросу пользователя.
- Формировать ответы на основе найденных материалов.
- Сделать удобный пользовательский интерфейс и сохранять контекст диалога.

## Оценивание

Оба кейса входят в одну номинацию ML-product. Максимальная оценка — 100 баллов.

| Критерий организаторов | Баллы | Что подготовить к показу |
| --- | ---: | --- |
| Презентация решения и ответы на вопросы | 15 | Показать живой диалог и объяснить границы покрытия. |
| Code Review | 25 | Показать контракты модулей, воспроизводимый запуск и проверки в CI. |
| Объём собранных и обработанных данных для базы знаний | 15 | Показать обработанные источники, охват вузов и предметных областей, дату обновления и способ подсчёта. |
| Качество ответов, логичность поведения и устойчивость к галлюцинациям и prompt injection | 30 | Показать eval, цитаты, уточнения, отказ при нехватке данных и результаты защитных проверок. |
| Функциональность интерфейса и пользовательский опыт | 15 | Показать диалог, уточнения, состояния ответа и переход к источникам. |
| **Итого** | **100** | |

Источник критериев — публикация организаторов ML-product, предоставленная командой. Проверяемые требования к решению описаны в [спецификации кейса](spec.md).
