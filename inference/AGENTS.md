# Inference

- FastAPI владеет внутренним контрактом `/inference/v1` на порту 8002. Потребители — Go для вложений и агент для генерации и распознавания.
- Храни ключи RouterAI только в окружении инференса. При выносе на отдельный хост включай внутренний токен и используй закрытую сеть или TLS.
- Клиенты передают разрешённые байты. Для PDF передавай уже выделенную страницу скана. Go извлекает текстовый слой и выбирает страницы. Чаты, файлы и доменные решения принадлежат потребителям.
- При смене провайдера сохрани форму результата и ошибки, обнови возможности и метрики. Воспроизводи интеграцию с подставным провайдером до живого прогона.
- Обновляй снимок [OpenAPI](../docs/api/inference.openapi.json) при изменении маршрутов. Запускай `make -C deploy check` и `make -C deploy smoke` при изменении связки.

## Границы пакета

| Модуль | Ответственность |
| --- | --- |
| `app.py` | Собирает приложение, операции и адаптер провайдера. |
| `api/routes.py` | HTTP-маршруты и авторизация. |
| `api/schemas.py` | Схемы запросов и ответов и перевод HTTP-входа в сущности. |
| `api/middleware.py` | Лимит тела запроса, корреляция логов и преобразование ошибок в HTTP-ответы. |
| `application/operations.py` | Проверка параметров и запуск генерации, ASR и OCR через порт провайдера. |
| `domain/` | Сущности операций, ошибки и протокол провайдера. |
| `config.py` | Настройки запуска, лимиты и промпты адаптера. |
| `runtime/` | Параллелизм, метрики и структурированные события. |
| `providers/` | Формирует запросы конкретного провайдера и нормализует результаты. |

`RouterAIProvider` реализует `Provider` и использует официальный OpenAI SDK с адресом RouterAI. Передавай расширения RouterAI через `extra_body`. Сохраняй фактический расход и PDF-аннотации из ответа. Автоматические повторы провайдера отключены. Подключай адаптер в `app.py`, передавай конфигурацию через конструктор и используй абсолютные импорты от пакета `inference`.

Настройки читает Pydantic Settings. Имена моделей, адрес и ключ задавай в `.env`. Дефолты перечислены в `.env.example`. Публичные промпты OCR храни отдельными TXT-файлами в `prompts/`. Рабочий текст подменяй в локальной `.private/prompts/` файлом с тем же именем. Переменные окружения имеют приоритет. Тесты подставляют провайдера без сетевых вызовов.

В публичном шаблоне указывай только общее назначение OCR. Правила проверок и защитные инструкции держи в `.private/prompts/`.

Метрики публикует Prometheus Client. Задержку записывай в `neti_inference_duration_seconds`, а расход — в счётчики. Настраивай события через `INFERENCE_LOG_LEVEL`. Логируй ID запроса, операцию, статус, модель, время и числовой расход без содержимого запросов и ответов.

Из каталога `inference/` запускай проверку командой `PYTHONPATH=src uv run --locked python -m unittest discover -s tests`.

`POST /inference/v1/decide` выполняет один выбор из ограниченного набора. Сервис проверяет выбранный ключ и применяет отдельный таймаут `DECISION_TIMEOUT_SECONDS`. Правила маршрутизации и реакции на результат хранятся у вызывающего сервиса. Метрики решения идут с `operation="decision"`.
